# 万能视频下载网站 — 需求分析文档

> 本文档供后续 AI 扩展功能时优先阅读，了解项目背景、需求边界与验收标准。

## 1. 项目背景与目标

### 1.1 背景

许多用户有将在线视频保存到本地的需求，但各平台存在以下痛点：

- 不支持直接下载
- 下载入口隐藏或操作繁琐
- 不支持批量下载
- 清晰度受限
- 移动端下载体验差

### 1.2 项目目标

构建一个**万能视频下载网站**，让用户能够：

- 更快速地从各平台下载视频
- 随时随地使用（含手机端）
- 选择合适清晰度与格式
- 已具备 AI 总结与登录/付费；后续按需扩展字幕翻译、批量等

### 1.3 产品定位

- **已交付**：核心下载 + 登录/Stripe Pro（下载额度）+ AI 总结（全站免费）+ 多语言 UI
- **后续**：体验增强（批量、历史、字幕翻译）；Stripe Live；Team 等

## 2. 用户画像与使用场景

| 用户类型 | 典型场景 |
|----------|----------|
| 学生 | 保存网课、教程视频离线学习 |
| 自媒体创作者 | 收集素材、参考案例 |
| 普通用户 | 收藏喜欢的视频，无网时观看 |
| 移动端用户 | 在手机浏览器中粘贴链接直接下载 |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | URL 解析 ≤ 60s；支持 3 路并发下载 |
| 可用性 | Docker 一键启动；前后端分离 |
| 兼容性 | Chrome、Safari、移动端微信内置浏览器（提示跳转） |
| 轻量 | 下载 Job 无独立 DB（内存 + 临时文件）；用户/订阅用 SQLite |
| 安全 | IP 解析限流 60 次/小时；Job TTL 2 小时自动清理 |
| UI | 对标 ai.codefather.cn/painting 风格，一次性完整交付 |

## 5. 合规与约束

1. **免责声明**：仅限个人学习/已有版权内容，用户自行承担法律责任
2. **yt-dlp Unlicense**：分发时保留源码链接与许可说明（见 README）
3. **平台 ToS**：不永久存储视频，仅临时中转；不做批量爬取
4. **限流**：防止滥用，公开服务需 IP 限流

## 6. 验收标准（Phase 1）

1. Chrome 桌面端：YouTube URL → 解析 → 选格式 → 下载 mp4 成功
2. 手机 Safari：B站 URL → 完成下载保存
3. UI：导航/Hero/URL 输入/平台标签/下载页/定价页/Footer 完整，风格一致（首页不再堆 Pro 功能列表）
4. 文档：requirements.md、design.md 完整可读
5. 部署：`docker compose up` 可本地一键启动；生产见 `docs/deploy-online-guide.md`（`docker-compose.yml` + `docker-compose.prod.yml` + Caddy HTTPS）
