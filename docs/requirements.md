# 万能视频下载网站 — 需求分析文档

> 本文档供后续 AI 扩展功能时优先阅读，了解项目背景、需求边界与验收标准。

## 1. 项目背景与目标

### 1.1 背景

许多用户有将在线视频保存到本地的需求，但各平台存在以下痛点：

- 不支持直接下载
- 下载入口隐藏或操作繁琐
- 不支持批量下载
- 清晰度受限
- 移动端下载体验差

### 1.2 项目目标

构建一个**万能视频下载网站**，让用户能够：

- 更快速地从各平台下载视频
- 随时随地使用（含手机端）
- 选择合适清晰度与格式
- 后续按需扩展 AI 总结、字幕翻译、付费能力

### 1.3 产品定位

- **Phase 1**：免费核心下载工具 + 付费功能占位（引导转化）
- **Phase 2+**：体验增强（批量、历史）
- **Phase 3+**：商业化（登录、付费、AI）

## 2. 用户画像与使用场景

| 用户类型 | 典型场景 |
|----------|----------|
| 学生 | 保存网课、教程视频离线学习 |
| 自媒体创作者 | 收集素材、参考案例 |
| 普通用户 | 收藏喜欢的视频，无网时观看 |
| 移动端用户 | 在手机浏览器中粘贴链接直接下载 |

## 3. 功能需求清单

### Phase 1 — MVP（本次交付）

| ID | 功能 | 优先级 | 说明 |
|----|------|--------|------|
| F1.1 | URL 粘贴与解析 | P0 | 用户粘贴视频链接，后端解析标题、缩略图、可用格式 |
| F1.2 | 格式/清晰度选择 | P0 | 720p / 1080p / 最佳画质 / 仅音频 |
| F1.3 | 单视频下载 | P0 | 下载到服务器临时目录，提供直链保存 |
| F1.4 | 下载进度展示 | P0 | SSE 实时推送 0–100% 进度；完成后自动唤起浏览器保存 |
| F1.5 | 平台支持展示 | P0 | 首页紧凑标签展示 YouTube、B站、TikTok 等 |
| F1.6 | Pro 功能占位 | P0 | AI 总结（已可用）、字幕翻译、批量 4K 等；紧凑列表展示 |
| F1.7 | 定价页 | P0 | Free / Pro / Team 三档对比 |
| F1.8 | 移动端适配 | P0 | 响应式布局 + iOS Safari 直链下载 + 微信浏览器提示 |
| F1.9 | 免责声明 | P0 | Footer 展示个人学习用途、版权说明 |

### Phase 2 — 体验增强（后续）

| ID | 功能 | 说明 |
|----|------|------|
| F2.1 | 批量 URL 下载 | 多行粘贴，队列处理 |
| F2.2 | 播放列表/合集 | 限制条目数防滥用 |
| F2.3 | 下载历史 | localStorage 存储，无 DB |
| F2.4 | 深色模式 | 主题切换 |

### Phase 3 — 商业化（后续）

| ID | 功能 | 说明 |
|----|------|------|
| F3.1 | 用户登录 | JWT + SQLite |
| F3.2 | 付费套餐 | 次数/清晰度限制，Stripe 或微信支付 |
| F3.3 | AI 视频总结 | 解析后自动触发；字幕或 ASR + DeepSeek SSE + markmap + 问答；同屏布局；Markdown / 导图导出 / 字幕下载（见 docs/ai-summary.md） |
| F3.4 | 字幕翻译 | yt-dlp 提取字幕 + 翻译 API |

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | URL 解析 ≤ 60s；支持 3 路并发下载 |
| 可用性 | Docker 一键启动；前后端分离 |
| 兼容性 | Chrome、Safari、移动端微信内置浏览器（提示跳转） |
| 轻量 | MVP 无数据库，内存 Job + 临时文件 |
| 安全 | IP 限流 10 次/小时；Job TTL 2 小时自动清理 |
| UI | 对标 ai.codefather.cn/painting 风格，一次性完整交付 |

## 5. 合规与约束

1. **免责声明**：仅限个人学习/已有版权内容，用户自行承担法律责任
2. **yt-dlp GPLv3**：Docker 镜像需保留源码链接
3. **平台 ToS**：不永久存储视频，仅临时中转；不做批量爬取
4. **限流**：防止滥用，公开服务需 IP 限流

## 6. 验收标准（Phase 1）

1. Chrome 桌面端：YouTube URL → 解析 → 选格式 → 下载 mp4 成功
2. 手机 Safari：B站 URL → 完成下载保存
3. UI：导航/Hero/URL 输入/平台卡片/Pro 卡片/下载页/定价页/Footer 完整，风格一致
4. 文档：requirements.md、design.md 完整可读
5. 部署：`docker compose up` 一键启动

## 7. 术语表

| 术语 | 说明 |
|------|------|
| Job | 一次解析/下载任务，有唯一 jobId |
| yt-dlp | 开源视频下载工具，支持 1000+ 站点 |
| SSE | Server-Sent Events，用于推送下载进度 |
